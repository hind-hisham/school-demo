# نظام إدارة المدرسة الذكي — نسخة تجريبية (Demo)

مشروع Next.js 15 بواجهة عربية RTL وبيانات وهمية بالكامل، يضم الموقع التعريفي وبوابات الإدارة والمعلم وولي الأمر والطالب.

## التشغيل على جهازك
1. ثبّت Node.js (الإصدار 18.18 أو أحدث).
2. داخل مجلد المشروع:
   npm install
   npm run dev
3. افتح http://localhost:3000

## النشر ليتفقده العملاء
ارفع المجلد إلى GitHub ثم اربطه بـ Vercel أو Netlify (الأمر: npm run build). تُحفظ التعديلات التجريبية في متصفح كل زائر ولا تؤثر على غيره.

ملاحظة: كُتب المشروع في بيئة لا تسمح بتثبيت الحزم، فلم يُبنَ ولم يُختبر في متصفح. إن ظهر خطأ عند npm run build فأرسله لإصلاحه.
